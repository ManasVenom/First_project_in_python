# First Project - Pygame

A beginner-level game developed using Python and Pygame.

## Features

- Main menu with Play button
- Four-directional player movement
- Apple collection and scoring system
- Boundary collision detection
- Game over screen
- Retry functionality
- Maximum score tracking

## Requirements

- Python 3
- Pygame
- Pygame GUI

## Installation

Install the required packages:

pip install -r requirements.txt

## Run the Game

python main.py
